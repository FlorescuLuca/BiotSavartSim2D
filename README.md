# 2D Biot-Savart Electromagnetic Field Simulator

A real-time 2D vector field simulator built with **C++17** and **OpenGL**. The application computes magnetic flux density ($\vec{B}$) generated by arbitrary current-carrying wires and visualizes field vectors dynamically across a spatial grid using procedural geometry and GLSL shaders.

## Key Features
* **Real-time Vector Field Visualization:** Computes vector direction and magnitude at grid points using the Biot-Savart superposition principle.
* **Procedural Arrow Rendering:** Generates arrow geometry and color intensity mapping dynamically on the GPU.
* **Interactive Wire Placement:** Left-click anywhere on the viewport to spawn new conductors with randomized current values.

## Tech Stack
* **Language:** C++17
* **Graphics API:** OpenGL (via GLAD loader)
* **Windowing & Input:** GLFW
* **Math Library:** GLM (OpenGL Mathematics)
* **Build System:** CMake

## Prerequisites
* C++17 compatible compiler (`g++`, `clang++`, or `MSVC`)
* CMake 3.10+
* OpenGL drivers

## Building and Running

```bash
# Clone the repository
git clone [https://github.com/FlorescuLuca/BiotSavartSim2D.git](https://github.com/FlorescuLuca/BiotSavartSim2D.git)
cd simv2

# Configure and build using CMake
cmake -B build
cmake --build build

# Run the simulator
cd build
./BiotSavartSim.exe
